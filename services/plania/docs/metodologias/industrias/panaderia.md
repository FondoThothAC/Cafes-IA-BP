# 🏭 Guía para Panaderías - Estándares de Industria México

## Resumen

Esta guía contiene datos de referencia para negocios de panadería en México, incluyendo normativas, costos típicos, salarios y márgenes de la industria.

---

## Normativas Aplicables

### NOM-251-SSA1-2009
**Prácticas de higiene para el proceso de alimentos, bebidas o suplementos alimenticios**

#### Requisitos Principales:
| Área | Requisito |
|------|-----------|
| **Instalaciones** | Pisos, paredes y techos lavables y sin grietas |
| **Agua** | Agua potable para elaboración |
| **Personal** | Uniforme limpio, cofia, cubrebocas si manipula |
| **Almacenamiento** | Separación de materias primas y producto terminado |
| **Temperatura** | Control de temperatura en ingredientes perecederos |
| **Limpieza** | Programa documentado de limpieza y sanitización |
| **Plagas** | Programa de control de plagas |

#### Documentación Requerida:
- Registro de proveedores
- Registro de limpieza
- Registro de control de plagas
- Registro de temperaturas (si aplica refrigeración)

## Punto de Equilibrio

### Fórmula
```
Punto de Equilibrio = Costos Fijos / Margen de Contribución

Donde:
Margen de Contribución = (Precio - Costo Variable) / Precio
```

### Ejemplo Panadería Pequeña
```
Costos Fijos Mensuales: $35,000
Precio Promedio por Pieza: $10
Costo Variable por Pieza: $4
Margen de Contribución: ($10 - $4) / $10 = 60%

Punto de Equilibrio = $35,000 / 0.60 = $58,333 ventas/mes
                    = 5,833 piezas/mes
                    = 194 piezas/día (30 días)
```
