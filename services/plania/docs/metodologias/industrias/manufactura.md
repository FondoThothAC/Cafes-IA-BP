## Métricas de Manufactura

### Eficiencia Operativa

| Métrica | Fórmula | Meta General |
|---------|---------|--------------|
| **OEE** | Disponibilidad × Rendimiento × Calidad | >85% |
| **Disponibilidad** | Tiempo productivo / Tiempo planeado | >90% |
| **Rendimiento** | Producción real / Producción teórica | >95% |
| **Calidad** | Piezas buenas / Total producidas | >99% |
| **Takt Time** | Tiempo disponible / Demanda | Variable |
| **Cycle Time** | Tiempo por unidad | < Takt Time |
| **Lead Time** | Orden → Entrega | Minimizar |

### Costos de Manufactura

| Componente | % del Costo Total | Notas |
|------------|-------------------|-------|
| **Materia prima** | 40-60% | Principal driver |
| **Mano de obra directa** | 15-25% | Incluye prestaciones |
| **Overhead (GIF)** | 15-25% | Renta, luz, supervisión |
| **Empaque** | 3-8% | Según producto |
| **Desperdicio/Merma** | 2-8% | Meta: <3% |

### Capacidad

```
Capacidad = (Horas × Días × Máquinas × Eficiencia) / Tiempo por pieza

Ejemplo:
- 8 horas × 22 días × 2 máquinas × 85% OEE = 299 horas efectivas
- Si cada pieza toma 0.5 horas: 299 / 0.5 = 598 piezas/mes
```

## Prompts para Agente Bob

### Cálculo de Capacidad
```
Para una planta con:
- {num_maquinas} máquinas
- {horas_dia} horas/día × {dias_mes} días/mes
- Tiempo por pieza: {minutos_pieza} minutos
- OEE estimado: {oee}%

Calcula:
1. Capacidad teórica mensual
2. Capacidad real (con OEE)
3. Si la demanda es {demanda} piezas, ¿alcanza?
4. Cuántas máquinas adicionales necesita
```

### Costeo de Producto
```
Para un producto manufacturado con:
- Materia prima: ${costo_mp}
- Tiempo de producción: {minutos} minutos
- Costo hora mano de obra: ${costo_mo_hora}
- Overhead mensual: ${overhead}
- Producción mensual: {unidades}

Calcula:
1. Costo primo por unidad
2. Costo de conversión
3. Costo total de manufactura
4. Precio sugerido (margen {margen}%)
```
