# 🍽️ Guía para Restaurantes - Estándares de Industria México

## Resumen

Esta guía contiene datos de referencia para negocios de restaurantes y establecimientos de alimentos en México, incluyendo normativas, costos típicos, salarios y márgenes de la industria.

### Fórmula de Food Cost
```
Food Cost % = (Costo de Ingredientes / Precio de Venta) × 100

Ejemplo:
- Costo ingredientes taco: $8
- Precio venta: $25
- Food Cost: 8/25 = 32%
```

## Capacidad y Operación

### Rotación de Mesas

| Tipo | Rotación/Día |
|------|--------------|
| Fast food | 8-15 veces |
| Casual | 2-4 veces |
| Fine dining | 1-2 veces |

### Cálculo de Capacidad
```
Ventas Potenciales = Mesas × Sillas × Rotación × Ticket × Días

Ejemplo:
- 10 mesas × 4 sillas = 40 lugares
- Rotación: 3 veces/día
- Ticket: $250
- Días: 26/mes

Ventas = 40 × 3 × $250 × 26 = $780,000/mes
```

## Indicadores Clave (KPIs)

| KPI | Fórmula | Meta |
|-----|---------|------|
| **Food Cost** | Costo MP / Ventas | < 35% |
| **Labor Cost** | Nómina / Ventas | < 30% |
| **Prime Cost** | (Food + Labor) / Ventas | < 65% |
| **Ocupación** | Clientes / Capacidad | > 70% |
| **Rotación mesas** | Comensales / Mesas / Día | > 2.5x |
| **Ticket promedio** | Ventas / # Transacciones | Según tipo |
| **RevPASH** | Ventas / (Lugares × Horas) | > $50/lugar/hora |

## Punto de Equilibrio

### Ejemplo Restaurante Casual (50 lugares)

```
Costos Fijos Mensuales:
- Renta: $35,000
- Nómina: $80,000
- Servicios: $15,000
- Otros: $10,000
- Total: $140,000

Food Cost: 32%
Margen de Contribución: 68%

Punto de Equilibrio = $140,000 / 0.68 = $205,882/mes
Por día (26 días): $7,919
Ticket $300: 26 clientes/día mínimo
```
