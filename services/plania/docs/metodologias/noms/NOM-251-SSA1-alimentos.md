# 📝 NOM-251-SSA1-2009 - Prácticas de Higiene para Alimentos

## Datos de la Norma

| Campo | Valor |
|-------|-------|
| **Nombre Completo** | NOM-251-SSA1-2009, Prácticas de higiene para el proceso de alimentos, bebidas o suplementos alimenticios |
| **Publicación** | DOF 01-03-2010 |
| **Entrada en vigor** | 01-09-2010 |
| **Ámbito** | Establecimientos que procesan alimentos |

---

## Objetivo

Establecer los requisitos mínimos de buenas prácticas de higiene que deben observarse en el proceso de alimentos, bebidas o suplementos alimenticios y sus materias primas.

---

## Aplicaciones

### ¿A quién aplica?
- Panaderías y pastelerías
- Restaurantes y fondas
- Carnicerías y pollerías
- Tortillerías
- Procesadores de alimentos
- Cafeterías y juguerías
- Tiendas de autoservicio (área de preparación)
- Comedores industriales

### ¿A quién NO aplica?
- Empresas con instalaciones de más de 10 empleados (requiere NOM-120)
- Productos del mar frescos (NOM-242)
- Establecimientos de bebidas alcohólicas (NOMs específicas)

---

## Requisitos por Categoría

### 1. Instalaciones y Áreas

| Elemento | Requisito |
|----------|-----------|
| **Pisos** | Lisos, lavables, sin grietas, pendiente hacia drenaje |
| **Paredes** | Lisas, en colores claros, lavables hasta 1.8m mínimo |
| **Techos** | Sin acumulación de suciedad, sin goteras |
| **Puertas** | Cierre automático, cortinas de aire o plástico |
| **Ventanas** | Con malla mosquitera |
| **Iluminación** | Suficiente, focos protegidos |
| **Ventilación** | Evitar condensación, sin corrientes cruzadas |
| **Drenaje** | Con coladeras y trampas de grasa |

### 2. Servicios

| Servicio | Requisito |
|----------|-----------|
| **Agua** | Potable, suficiente para operación |
| **Depósitos de agua** | Limpios, tapados, accesibles para limpieza |
| **Hielo** | De agua potable, protegido |
| **Vapor** | Limpio, de grado alimenticio |

### 3. Control de Plagas

| Elemento | Frecuencia |
|----------|------------|
| **Fumigación** | Mensual o según necesidad |
| **Inspección** | Semanal |
| **Registros** | Documentar cada servicio |
| **Trampas** | En puntos estratégicos, numeradas |

### 4. Personal

| Requisito | Detalle |
|-----------|---------|
| **Uniforme** | Limpio, color claro, exclusivo |
| **Cofia/gorra** | Obligatoria, debe cubrir todo el cabello |
| **Cubrebocas** | Si manipula alimentos listos para consumo |
| **Calzado** | Cerrado, antideslizante |
| **Uñas** | Cortas, limpias, sin esmalte |
| **Sin joyas** | Anillos, pulseras, aretes |
| **Lavado de manos** | Antes de manipular, después de ir al baño |
| **Enfermedades** | No laborar con enfermedades respiratorias, gastrointestinales o heridas |

### 5. Almacenamiento

| Tipo | Requisitos |
|------|------------|
| **General** | Estantes a 15cm del piso mínimo |
| **Refrigeración** | < 4°C para perecederos |
| **Congelación** | < -18°C |
| **Secos** | Frescos, secos, ventilados |
| **PEPS** | Primeras Entradas, Primeras Salidas |
| **Separación** | Crudos separados de cocidos |

### 6. Proceso

| Etapa | Requisito |
|-------|-----------|
| **Recepción** | Verificar temperaturas, rechazar defectuosos |
| **Lavado** | Desinfectar frutas y verduras |
| **Preparación** | Áreas separadas para crudos y cocidos |
| **Cocción** | Temperaturas internas seguras (ver tabla) |
| **Enfriamiento** | De 60°C a 4°C en menos de 4 horas |
| **Recalentamiento** | Hasta 74°C mínimo |

#### Temperaturas de Cocción Seguras

| Alimento | Temperatura Interna |
|----------|---------------------|
| Aves | 74°C |
| Carne molida | 69°C |
| Cerdo | 63°C |
| Res (término medio) | 63°C |
| Pescado | 63°C |
| Huevo | Yema y clara firmes |

## Documentación Requerida

### Registros Obligatorios

| Registro | Contenido | Frecuencia |
|----------|-----------|------------|
| **Control de plagas** | Fecha, empresa, productos usados | Cada servicio |
| **Limpieza y desinfección** | Áreas, productos, responsable | Diario |
| **Temperaturas** | Refrigeradores, congeladores | Diario (2 veces) |
| **Recepción de materias primas** | Proveedor, lote, condiciones | Cada entrega |
| **Capacitación** | Tema, asistentes, fecha | Cada evento |

### Programa de Limpieza

| Área | Frecuencia | Productos |
|------|------------|-----------|
| Pisos | Diario | Detergente + cloro |
| Paredes | Semanal | Detergente |
| Equipos | Después de uso | Detergente + sanitizante |
| Refrigeradores | Semanal | Detergente + bicarbonato |
| Almacén | Semanal | Aspirado + trapeado |
