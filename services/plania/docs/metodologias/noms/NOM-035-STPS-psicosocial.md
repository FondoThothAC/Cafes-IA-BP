# 📋 NOM-035-STPS-2018 - Factores de Riesgo Psicosocial

## Datos de la Norma

| Campo | Valor |
|-------|-------|
| **Nombre Completo** | NOM-035-STPS-2018, Factores de riesgo psicosocial en el trabajo |
| **Publicación** | DOF 23-10-2018 |
| **Entrada en vigor** | Fase 1: 23-10-2019 / Fase 2: 23-10-2020 |
| **Ámbito** | Todos los centros de trabajo |

---

## Objetivo

Establecer los elementos para identificar, analizar y prevenir los factores de riesgo psicosocial, así como para promover un entorno organizacional favorable en los centros de trabajo.

---

## Aplicación por Tamaño

| Tamaño | Empleados | Obligaciones |
|--------|-----------|--------------|
| **Hasta 15** | 1-15 | Política, identificación de eventos traumáticos |
| **16-50** | 16-50 | + Identificación de factores de riesgo |
| **Más de 50** | 51+ | + Evaluación del entorno organizacional |

---

## Obligaciones del Patrón

## Factores de Riesgo Psicosocial

### Categorías

| Factor | Ejemplos |
|--------|----------|
| **Condiciones del ambiente** | Ruido, iluminación, temperatura |
| **Cargas de trabajo** | Jornadas extensas, ritmo acelerado |
| **Falta de control** | Sin autonomía, exceso de supervisión |
| **Jornada de trabajo** | Horarios rotativos, sin descansos |
| **Interferencia trabajo-familia** | No poder atender asuntos personales |
| **Liderazgo negativo** | Jefe autoritario, falta de apoyo |
| **Relaciones negativas** | Conflictos, aislamiento, acoso |
| **Violencia laboral** | Hostigamiento, acoso, malos tratos |

### Eventos Traumáticos Severos

- Amenaza de muerte
- Asaltos con violencia
- Secuestros
- Accidentes graves
- Actos violentos

## Cuestionarios Oficiales

### Guía de Referencia I
**Identificación de eventos traumáticos**
- 20 preguntas
- Aplica a quienes hayan experimentado eventos
- Respuestas: Sí/No

### Guía de Referencia II
**Factores de riesgo psicosocial (16-50 empleados)**
- 46 preguntas
- 5 categorías
- Puntuación: 0-4 puntos

### Guía de Referencia III
**Entorno organizacional (+50 empleados)**
- 72 preguntas
- Incluye todo del II + entorno
- Evaluación más completa

## Programa de Intervención

### Acciones por Nivel de Riesgo

**Bajo (Preventivo):**
- Campañas de comunicación
- Pausas activas
- Actividades de integración

**Medio (Control):**
- Capacitación en manejo de estrés
- Revisión de cargas de trabajo
- Mejora de liderazgo

**Alto (Intervención):**
- Atención psicológica
- Restructuración de procesos
- Rotación de puestos
- Acciones disciplinarias

**Muy Alto (Urgente):**
- Separación temporal de involucrados
- Intervención de especialistas
- Denuncia ante autoridades (si aplica)
- Cambios organizacionales profundos

## Integración con Agente Bob

### Detección de Aplicabilidad

```python
def determine_nom035_obligations(employees: int) -> dict:
    """
    Determina las obligaciones de NOM-035 según número de empleados.
    """
    base_obligations = [
        "Política de prevención",
        "Medidas contra violencia laboral",
        "Identificación de eventos traumáticos"
    ]
    
    if employees <= 15:
        return {
            "nivel": "Básico (1-15 empleados)",
            "obligaciones": base_obligations,
            "guias": ["Guía I"],
            "costo_estimado": "5,000 - 10,000 MXN"
        }
    elif employees <= 50:
        return {
            "nivel": "Intermedio (16-50 empleados)",
            "obligaciones": base_obligations + [
                "Evaluación de factores de riesgo (Guía II)"
            ],
            "guias": ["Guía I", "Guía II"],
            "costo_estimado": "10,000 - 30,000 MXN"
        }
    else:
        return {
            "nivel": "Completo (51+ empleados)",
            "obligaciones": base_obligations + [
                "Evaluación de factores de riesgo (Guía II)",
                "Evaluación de entorno organizacional (Guía III)"
            ],
            "guias": ["Guía I", "Guía II", "Guía III"],
            "costo_estimado": "30,000 - 100,000 MXN"
        }
```
