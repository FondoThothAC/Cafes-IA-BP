# 📚 Lean Startup - Metodología para Validación de Negocios

## Resumen Ejecutivo

**Lean Startup** es una metodología creada por Eric Ries para desarrollar negocios y productos de manera eficiente, minimizando el desperdicio y maximizando el aprendizaje validado.

> **Principio Central:** "Construir-Medir-Aprender" (Build-Measure-Learn)

---

## Los 5 Principios Fundamentales

### 1. Los Emprendedores Están en Todas Partes
- No necesitas un garaje en Silicon Valley
- Cualquier persona que crea algo nuevo bajo incertidumbre es un emprendedor
- Aplica a startups, corporativos, gobierno y ONGs

### 2. Emprendimiento es Administración
- Una startup es una institución, no solo un producto
- Requiere un nuevo tipo de gestión adaptada a la incertidumbre
- El progreso se mide en APRENDIZAJE, no en ganancias inmediatas

### 3. Aprendizaje Validado
- El objetivo es aprender qué es lo que los clientes realmente quieren
- No es suficiente "creer" - hay que PROBAR con datos
- Cada experimento debe tener una hipótesis clara y métricas

### 4. Construir-Medir-Aprender
- **Construir:** Crear un MVP (Producto Mínimo Viable)
- **Medir:** Recopilar datos de uso real
- **Aprender:** Analizar si se validó la hipótesis
- Ejecutar este ciclo lo más rápido posible

### 5. Contabilidad de Innovación
- Métricas accionables vs. métricas de vanidad
- Establecer línea base, ajustar el motor, pivotear o perseverar
- Los hitos de aprendizaje son más importantes que los hitos de producto

## Producto Mínimo Viable (MVP)

### ¿Qué es?
El MVP es la versión más simple de tu producto que te permite iniciar el ciclo de aprendizaje con el mínimo esfuerzo.

### Tipos de MVP

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Landing Page** | Página web que describe el producto y mide interés | Dropbox (video demo) |
| **Concierge** | Servicio manual que simula el producto | Food on the Table |
| **Mago de Oz** | Parece automatizado pero es manual detrás | Zappos (fotos de zapatos) |
| **Smoke Test** | Botón de "comprar" antes de que exista | Buffer |
| **Video Demo** | Video explicando el producto | Dropbox |
| **Crowdfunding** | Validar demanda con pre-ventas | Pebble Watch |

### Reglas del MVP
1. **Mínimo≠** Basura - Debe resolver el problema core
2. **Viable** = Alguien pagaría por esto
3. **Producto** = Entrega valor real

## Pivotar vs. Perseverar

### ¿Cuándo Pivotar?
- Los experimentos no validan las hipótesis
- El crecimiento es plano o negativo
- Los clientes no regresan (baja retención)
- El modelo de negocio no es sostenible

### Tipos de Pivote

| Pivote | Descripción |
|--------|-------------|
| **Zoom-in** | Una característica se vuelve el producto completo |
| **Zoom-out** | El producto se vuelve una característica de algo más grande |
| **Segmento de Cliente** | Cambiar a quién le vendes |
| **Necesidad del Cliente** | El problema que resuelves es diferente |
| **Plataforma** | Cambiar de app a plataforma o viceversa |
| **Arquitectura de Negocio** | Alto margen/bajo volumen ↔ bajo margen/alto volumen |
| **Canal** | Cambiar cómo llegas al cliente |
| **Tecnología** | Usar diferente tecnología para el mismo resultado |

## Métricas para Startups

### Métricas de Vanidad (EVITAR)
- Total de usuarios registrados
- Total de descargas
- Páginas vistas totales
- "Crecimiento" sin contexto

### Métricas Accionables (USAR)
- **Tasa de Conversión:** % de visitantes que se vuelven clientes
- **Retención:** % de clientes que regresan
- **Churn:** % de clientes que abandonan
- **LTV (Lifetime Value):** Valor total de un cliente
- **CAC (Customer Acquisition Cost):** Costo de adquirir un cliente
- **NPS (Net Promoter Score):** Probabilidad de recomendación

### Cohortes
Analizar usuarios por fecha de adquisición, no en agregado:
```
Cohorte Enero:  100 usuarios → 60% retención mes 1 → 40% mes 2
Cohorte Febrero: 150 usuarios → 65% retención mes 1 → 45% mes 2
                                   ↑ Mejora medible
```

## Contabilidad de Innovación

### Los 3 Hitos de Aprendizaje

1. **Establecer Línea Base**
   - Lanzar MVP y medir estado inicial
   - Documentar métricas de punto de partida

2. **Sintonizar el Motor**
   - Hacer experimentos para mejorar métricas
   - Cada iteración debe acercar al ideal

3. **Pivotar o Perseverar**
   - Si el progreso es insuficiente → Pivotar
   - Si hay tracción → Perseverar y escalar

## Aplicación en PlanIA

### Para Proyectos Nuevos
1. **Hipótesis de Valor:** ¿El producto resuelve un problema real?
2. **Hipótesis de Crecimiento:** ¿Cómo crecerá el negocio?
3. **MVP recomendado:** Basado en complejidad del proyecto
4. **Métricas sugeridas:** Según tipo de negocio

### Preguntas Clave por Módulo

| Módulo | Pregunta Lean |
|--------|---------------|
| Estudio de Mercado | ¿Has hablado con 10 clientes potenciales? |
| Propuesta de Valor | ¿Tu MVP resuelve el problema #1 del cliente? |
| Finanzas | ¿CAC < LTV? |
| Marketing | ¿Qué canal tiene mejor conversión? |
