# 📋 Business Model Canvas - Modelo de Negocio

## Resumen

El **Business Model Canvas** es una herramienta de gestión estratégica creada por Alexander Osterwalder que permite visualizar y desarrollar modelos de negocio de manera estructurada.

> **Principio Central:** Un modelo de negocio describe la lógica de cómo una organización crea, entrega y captura valor.

## Detalle de Cada Bloque

### 1. 👥 Segmentos de Clientes
**Pregunta:** ¿Para quién creamos valor?

#### Tipos de Segmentos:
| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Mercado Masivo** | Sin distinción entre segmentos | Coca-Cola |
| **Nicho** | Segmento específico y especializado | Rolex |
| **Segmentado** | Grupos con necesidades ligeramente diferentes | Bancos (premium vs. básico) |
| **Diversificado** | Segmentos sin relación | Amazon (consumidores + AWS) |
| **Multi-sided** | Dos o más segmentos interdependientes | Uber (conductores + pasajeros) |

#### Datos a Capturar:
- Demografía (edad, género, ubicación)
- Psicografía (valores, intereses, estilo de vida)
- Comportamiento de compra
- Problema principal que resuelves

---

### 2. 💎 Propuesta de Valor
**Pregunta:** ¿Qué valor entregamos al cliente?

#### Tipos de Valor:
| Valor | Descripción |
|-------|-------------|
| **Novedad** | Satisface necesidades que no existían |
| **Desempeño** | Mejora el rendimiento de productos existentes |
| **Personalización** | Adaptado a las necesidades del cliente |
| **Diseño** | Valor en la estética y experiencia |
| **Marca/Status** | Valor percibido por la marca |
| **Precio** | Menor costo que alternativas |
| **Reducción de Costos** | Ayuda al cliente a ahorrar |
| **Reducción de Riesgos** | Garantías, seguros, confiabilidad |
| **Accesibilidad** | Disponible para quienes antes no podían |
| **Conveniencia** | Facilita la vida del cliente |

---

### 3. 📦 Canales
**Pregunta:** ¿Cómo llegamos a nuestros clientes?

#### Fases del Canal:
1. **Conocimiento:** ¿Cómo nos conocen?
2. **Evaluación:** ¿Cómo evalúan nuestra propuesta?
3. **Compra:** ¿Cómo compran?
4. **Entrega:** ¿Cómo entregamos el valor?
5. **Post-venta:** ¿Cómo damos soporte?

#### Tipos de Canales:
| Canal | Ejemplo |
|-------|---------|
| **Directo - Propio** | Tienda física, sitio web, app |
| **Directo - Fuerza de Ventas** | Vendedores propios |
| **Indirecto - Socios** | Distribuidores, retailers |
| **Indirecto - Mayoristas** | Ventas B2B |

---

### 4. 💬 Relación con Clientes
**Pregunta:** ¿Qué tipo de relación tenemos con cada segmento?

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Asistencia Personal** | Interacción humana directa | Bancos tradicionales |
| **Asistencia Dedicada** | Representante exclusivo | Banca privada |
| **Autoservicio** | Sin interacción, cliente se ayuda solo | IKEA, AMZ |
| **Automatizado** | Autoservicio + procesos automáticos | Netflix, Spotify |
| **Comunidades** | Usuarios interactúan entre sí | Stack Overflow |
| **Co-creación** | Clientes participan en crear valor | YouTube, Wikipedia |

---

### 5. 💵 Fuentes de Ingresos
**Pregunta:** ¿Por qué valor están dispuestos a pagar?

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Venta de Activos** | Venta de un producto físico | Retail |
| **Uso** | Cobro por uso del servicio | Electricidad, Uber |
| **Suscripción** | Acceso continuo por pago recurrente | Netflix, Gym |
| **Alquiler/Leasing** | Acceso temporal a un activo | Airbnb, Enterprise |
| **Licencias** | Permiso para usar propiedad intelectual | Software, Patentes |
| **Comisión** | % por intermediar transacciones | Inmobiliarias, Brokers |
| **Publicidad** | Cobro por mostrar anuncios | Google, Facebook |

---

### 6. 🏢 Recursos Clave
**Pregunta:** ¿Qué recursos necesitamos para entregar valor?

| Tipo | Ejemplos |
|------|----------|
| **Físicos** | Instalaciones, maquinaria, vehículos, inventario |
| **Intelectuales** | Patentes, marcas, bases de datos, secretos |
| **Humanos** | Expertos, vendedores, desarrolladores |
| **Financieros** | Capital, líneas de crédito, acciones |

---

### 7. ⚙️ Actividades Clave
**Pregunta:** ¿Qué actividades son esenciales para el modelo?

| Categoría | Ejemplos |
|-----------|----------|
| **Producción** | Manufactura, diseño, desarrollo |
| **Resolución de Problemas** | Consultoría, servicios médicos |
| **Plataforma/Red** | Mantenimiento de la plataforma, matching |

---

### 8. 🤝 Socios Clave
**Pregunta:** ¿Quiénes son nuestros aliados estratégicos?

#### Tipos de Alianzas:
| Tipo | Descripción |
|------|-------------|
| **Alianzas Estratégicas** | Entre no-competidores |
| **Coopetición** | Entre competidores |
| **Joint Ventures** | Para desarrollar nuevos negocios |
| **Relación Proveedor** | Para asegurar suministros |

#### Motivaciones:
- Optimización y economías de escala
- Reducción de riesgo e incertidumbre
- Adquisición de recursos y actividades

---

### 9. 💰 Estructura de Costos
**Pregunta:** ¿Cuáles son los costos más importantes?

| Tipo | Descripción |
|------|-------------|
| **Costos Fijos** | No varían con producción (renta, salarios) |
| **Costos Variables** | Varían con producción (materias primas) |
| **Economías de Escala** | Costo unitario baja con volumen |
| **Economías de Alcance** | Compartir recursos entre productos |

#### Modelos de Negocio:
- **Orientado a Costos:** Minimizar gastos (Walmart, Ryanair)
- **Orientado a Valor:** Enfoque en calidad premium (Rolex, Apple)
