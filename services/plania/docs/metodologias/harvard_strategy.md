# 🎓 Harvard Business Strategy - Frameworks Estratégicos

## Resumen

Este documento recopila los principales frameworks de estrategia empresarial desarrollados y enseñados en Harvard Business School, particularmente los trabajos de **Michael Porter**.

## Las 5 Fuerzas de Porter

### Concepto
Framework para analizar la intensidad competitiva y el atractivo de una industria.

```
                    ┌─────────────────────┐
                    │  AMENAZA DE NUEVOS  │
                    │      ENTRANTES      │
                    │         ⬇️          │
                    └─────────────────────┘
                              │
                              ▼
┌─────────────┐     ┌─────────────────────┐     ┌─────────────┐
│   PODER DE  │     │    RIVALIDAD ENTRE  │     │  PODER DE   │
│ NEGOCIACIÓN │────▶│    COMPETIDORES     │◀────│ NEGOCIACIÓN │
│ PROVEEDORES │     │    EXISTENTES       │     │  CLIENTES   │
└─────────────┘     └─────────────────────┘     └─────────────┘
                              │
                              ▲
                    ┌─────────────────────┐
                    │  AMENAZA DE         │
                    │  PRODUCTOS          │
                    │  SUSTITUTOS         │
                    └─────────────────────┘
```

### 1. Rivalidad entre Competidores Existentes

| Factor | Alta Rivalidad | Baja Rivalidad |
|--------|----------------|----------------|
| **Número de competidores** | Muchos, similares | Pocos, uno domina |
| **Crecimiento industria** | Lento | Rápido |
| **Costos fijos** | Altos | Bajos |
| **Diferenciación** | Productos genéricos | Productos únicos |
| **Barreras de salida** | Altas | Bajas |

**Preguntas para análisis:**
- ¿Cuántos competidores directos hay?
- ¿El mercado está creciendo o estancado?
- ¿Los productos son diferenciables?

---

### 2. Amenaza de Nuevos Entrantes

| Barrera | Descripción |
|---------|-------------|
| **Economías de escala** | Necesidad de producir en volumen |
| **Diferenciación** | Lealtad a marcas existentes |
| **Requerimientos de capital** | Inversión inicial necesaria |
| **Costos de cambio** | Lo que cuesta al cliente cambiar |
| **Acceso a distribución** | Control de canales |
| **Regulación** | Licencias, permisos, normativas |

**Preguntas para análisis:**
- ¿Qué tan fácil es entrar a este mercado?
- ¿Hay regulaciones que protejan a los incumbentes?
- ¿Se necesita mucho capital?

---

### 3. Poder de Negociación de Proveedores

| Factor | Alto Poder | Bajo Poder |
|--------|------------|------------|
| **Concentración** | Pocos proveedores | Muchos proveedores |
| **Sustitutos** | Sin alternativas | Muchas alternativas |
| **Importancia** | Insumo crítico | Insumo genérico |
| **Integración** | Pueden venderte directo | No les interesa |

**Preguntas para análisis:**
- ¿Hay proveedores alternativos?
- ¿Qué tan único es el insumo?
- ¿Los proveedores podrían competir contigo?

---

### 4. Poder de Negociación de Clientes

| Factor | Alto Poder | Bajo Poder |
|--------|------------|------------|
| **Concentración** | Pocos compradores grandes | Muchos pequeños |
| **Estandarización** | Productos genéricos | Diferenciados |
| **Información** | Conocen alternativas | No saben de otras |
| **Integración** | Pueden producirlo ellos | No pueden |

**Preguntas para análisis:**
- ¿Tus clientes pueden negociar precios?
- ¿Hay alternativas fácilmente disponibles?
- ¿Los clientes son sensibles al precio?

---

### 5. Amenaza de Sustitutos

| Factor | Alta Amenaza | Baja Amenaza |
|--------|--------------|--------------|
| **Disponibilidad** | Muchos sustitutos | Pocos o ninguno |
| **Precio-rendimiento** | Sustituto mejor o igual | Inferior |
| **Costos de cambio** | Bajos | Altos |

**Preguntas para análisis:**
- ¿Qué otras soluciones tiene el cliente para el mismo problema?
- ¿Los sustitutos son más baratos o mejores?

## Estrategias Genéricas de Porter

### Las 3 Estrategias

```
                    ┌─────────────────────────────────────┐
                    │           VENTAJA COMPETITIVA       │
                    │                                     │
                    │    Costo Bajo        Diferenciación │
                    │        ▼                  ▼         │
        ┌───────────┼─────────────────┬─────────────────┤
        │  Amplio   │   LIDERAZGO     │  DIFERENCIACIÓN │
        │  Mercado  │   EN COSTOS     │                 │
 ALCANCE│           │   (Walmart)     │   (Apple)       │
        │───────────┼─────────────────┼─────────────────┤
        │  Enfoque  │   ENFOQUE       │  ENFOQUE EN     │
        │  (Nicho)  │   EN COSTOS     │  DIFERENCIACIÓN │
        │           │   (Spirit Air)  │   (Rolex)       │
        └───────────┴─────────────────┴─────────────────┘
```

### 1. Liderazgo en Costos
- Ser el productor de menor costo
- Vender a precio de mercado o ligeramente menor
- Requiere: eficiencia, escala, tecnología

### 2. Diferenciación
- Ofrecer algo único que justifique precio premium
- Basado en: calidad, marca, servicio, innovación
- Requiere: inversión en I+D, marketing, talento

### 3. Enfoque (Nicho)
- Concentrarse en un segmento específico
- Puede ser por costos o diferenciación
- Requiere: conocimiento profundo del nicho

### ⚠️ Stuck in the Middle
Empresas que no eligen una estrategia clara terminan:
- Sin ventaja en costos
- Sin diferenciación
- Con márgenes bajos y sin posición defendible
