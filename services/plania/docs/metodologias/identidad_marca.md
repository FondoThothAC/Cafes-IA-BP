## Elementos de Identidad Sugeridos

### Por Etapa del Negocio

| Etapa | Elementos Mínimos | Elementos Recomendados |
|-------|-------------------|------------------------|
| **Idea** | Nombre, paleta de colores | Logo básico, bio redes |
| **MVP/Validación** | + Logo simple, tipografía | + Perfil completo en 1 red |
| **Lanzamiento** | + Perfil en 2-3 redes | + Tarjetas, plantillas |
| **Crecimiento** | + Manual de marca básico | + Fotografía de producto/equipo |
| **Establecido** | + Branding completo | + Video institucional |

### Checklist de Identidad

```
[ ] Nombre del negocio definido
[ ] Paleta de 3-5 colores
[ ] Tipografía principal y secundaria
[ ] Logo en versiones: color, B&N, icono
[ ] Perfil en redes principales
[ ] Bio/descripción unificada
[ ] Fotos de perfil consistentes
[ ] Plantilla de posts
[ ] Firma de correo
[ ] Tarjeta de presentación
```

## Generación sin LLM

### Algoritmo de Sugerencia de Colores

```python
def suggest_colors(industry: str, personality: str) -> dict:
    """
    Sugiere paleta de colores basada en industria y personalidad.
    No requiere LLM.
    """
    color_map = {
        ("alimentos", "tradicional"): {
            "primary": "#8B4513",
            "secondary": "#F5DEB3", 
            "accent": "#D4A574"
        },
        ("alimentos", "moderno"): {
            "primary": "#2D3436",
            "secondary": "#00B894",
            "accent": "#FDCB6E"
        },
        ("tecnologia", "corporativo"): {
            "primary": "#2563EB",
            "secondary": "#6B7280",
            "accent": "#10B981"
        },
        # ... más combinaciones
    }
    
    key = (industry, personality)
    return color_map.get(key, color_map[("general", "moderno")])
```

### Algoritmo de Sugerencia de Tipografía

```python
def suggest_fonts(industry: str, target_audience: str) -> dict:
    """
    Sugiere combinación de tipografías.
    No requiere LLM.
    """
    if target_audience in ["jovenes", "millennials", "gen-z"]:
        return {
            "heading": "Poppins",
            "body": "Inter",
            "accent": "Space Grotesk"
        }
    elif industry in ["legal", "financiero", "corporativo"]:
        return {
            "heading": "Merriweather",
            "body": "Source Sans Pro",
            "accent": "IBM Plex Sans"
        }
    # Default moderno
    return {
        "heading": "Outfit",
        "body": "DM Sans",
        "accent": "JetBrains Mono"
    }
```
